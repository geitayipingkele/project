总览使用帮助

按单位查看
省级与地市是独立边缘节点。勾选省份只选择省级节点，展开省份后可另外勾选地市。

按链路定位
查询业务对象或打开链路列表，选择 Path 可突出完整路径。点击节点、装置或连线查看状态和引用。

多单位浏览
已选单位始终保留在顶部；使用“上一组 / 下一组”切换可见单位。网级公共对象在同一图中复用。

操作画布
拖动画布空白区域平移，滚动查看纵向拓扑；按住 Ctrl / ⌘ 并滚轮缩放。Esc 清除选择；方向键平移画布。
