# P01 链路监控总览与 P04 指标趋势原型

这是一个可直接打开的静态 HTML 原型，覆盖 P01「链路监控总览」以及从总览进入的 P04「指标趋势」页签。它使用本地 HTML、CSS、JavaScript 与 SVG，不依赖 CDN、构建工具或后端接口；不包含编排、配置等页面。

## 运行

直接双击 `index.html`，或以浏览器打开该文件；`file://` 协议可正常运行。也可将 `prototype/overview/` 目录整体上传到任意静态站点，入口仍为 `index.html`。

原型入口不需要安装依赖或启动构建服务。静态部署时保持当前目录结构即可。

## 目录

```text
overview/
├─ index.html              # P01 容器与静态控件
├─ README.md
└─ assets/
   ├─ styles.css           # 共享云控制台主题和组件样式
   ├─ shared.js            # 状态标签、时区等共享工具
   ├─ data.js              # 可替换的原型数据与状态聚合输入
   ├─ metrics-data.js      # 当前指标、方向/IP维度与趋势样例生成
   ├─ metrics-trend.js     # P04指标趋势页签和图表交互
   ├─ model.js             # 可在界面外运行的状态聚合与数据校验
   ├─ page-registry.js     # 页面注册、挂载、卸载接口
   └─ overview.js          # P01 查询、拓扑、详情和画布逻辑
```

## P01 已实现的边界

- 默认只显示已发布且启用的 Path；停用方向不进入实时图，只在相关业务对象查询时给出最后状态和时间的只读说明。
- 查询支持单位、业务对象、Path 名称或标识、链路类型。单位采用省—地市两级级联复选，省级和地市节点独立选择，勾选省级不会自动选择所属地市。
- 总览按网级、边缘节点两层组织，每层按一区至四区布局。跨区及跨层连接均经过防火墙、正向隔离或反向隔离装置。
- 边缘单位较多时保留完整已选清单，并通过上一组、下一组分批浏览；网级公共节点在图内复用。
- 选择业务对象会聚焦相关上、下行 Path；选择单个 Path 仅突出完整组成。两者都不改变 Node、Edge 或 Path 的状态聚合范围。
- Node、Edge 使用正常/异常/未知三态；Path 依据全部成员实时计算正常/异常/未知/部分异常/部分未知五态。业务对象没有整体状态或启停操作。
- Node 详情按 Path 展示 Role；Edge 详情展示源/目标、方向、业务作用、影响范围、状态来源、更新时间和引用 Path。示例含反向 Edge，以及同端点但业务作用/影响范围不同的多条 Edge。数据加载前会拒绝重复稳定标识或失效的 Node/Edge/Path 引用。
- 画布支持选择、异常定位、缩放、拖移、适应宽度、清除聚焦和刷新。连线采用带方向箭头的圆角正交路径，并为上下行及跨层连接设置独立走线通道。
- Path 摘要展示当前整链时延；Node/Edge 详情按对象类型展示当前指标。普通服务支持多IP聚合，隔离装置保留正反向指标，防火墙展示入出向吞吐量和当前连接数。
- P04“指标趋势”提供整链固定参照、单对象选择、1小时至30天及自定义范围、自动聚合粒度、统计口径切换、同量纲序列显隐、联动游标、状态区间和缺失断线。返回总览时不重建筛选、聚焦或画布状态。
- 不提供配置、编排、资源维护、发布、导入或启停入口。

## 后续页面扩展

为避免后续 P02–P06 把逻辑堆回 `index.html`，页面需要按如下方式注册：

1. 新建页面自己的脚本，例如 `assets/path-management.js`，并复用 `LinkMonitor.data`、`LinkMonitor.util` 与 `styles.css`。
2. 使用 `LinkMonitor.registerPage('path-management', { mount(root) { /* 初始化页面 */ }, unmount() { /* 释放事件或订阅 */ } })` 注册。
3. 在宿主入口需要切换时调用 `LinkMonitor.mountPage('path-management', root)`；该调用会先执行当前页面的 `unmount`。单页容器和导航由后续页面交付时添加。
4. 保持发布配置、运行状态和视图交互状态分层。筛选、聚焦、画布位置属于视图状态，不能改写 Path 聚合或发布配置。

当前原型不宣称可无成本迁移至 Vue；不过其数据对象、状态聚合函数和主题变量可在后续迁移时复用。

## 静态部署

部署时保留 `index.html` 与 `assets/` 的相对路径即可。目录中没有服务器路由、鉴权或真实数据读取逻辑；接入真实服务时，应由后端完成权限与状态有效期判断，前端只展示已授权的读取结果。
