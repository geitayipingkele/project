# P01 链路监控总览原型实施方案 V1.0

日期：2026-09-16。用户已同意 HTML 方案，要求支持后续配置等页面扩展，并参考 Vue 生态控件样式与规范。

## 1. 技术与交付

采用 HTML、CSS、原生 JavaScript、SVG。使用分文件结构，不依赖在线 CDN、后端或编译构建；浏览器直接打开 index.html 即可运行。共享样式、数据模型、页面逻辑和页面注册分离，为后续 P02–P06 扩展保留接口。当前不是 Vue 工程；控件视觉与行为参考 Element Plus，避免把仿照样式宣称为已安装 Vue 组件。

代码在 prototype/overview/，包含 index.html、共享样式/脚本、样例数据、总览逻辑及 README。采用普通 defer 脚本和命名空间注册，避免 file:// 模块加载限制。后续页面以独立注册对象加入页面容器，复用主题、数据及公共控件，不把整个应用写在一个 HTML 内。未来迁移 Vue 时可沿用对象数据、状态计算和设计变量；不是无成本自动迁移。

本轮不初始化远程仓库，不引入 npm 构建链；交付目录可复制到任意静态文件服务器。README 提供直接打开、本地 HTTP 预览、静态部署路径、目录结构和扩展说明；外网发布不在本次执行范围。

## 2. P01 功能边界

顶部单位、业务对象、Path、类型查询和重置；单位采用省—地市二级级联复选，省级节点与地市节点独立选择。左侧为 Path 列表，中央为网级—边缘节点两层四区融合拓扑，右侧为对象详情。实现业务双向聚焦、单 Path 聚焦、Node/Edge 选择、异常/未知对象定位、缩放/拖移/适应宽度/清除聚焦、刷新保持视口。多 Edge 与反向关系可辨，Role 按 Path 表达。

所有跨区及跨层关系必须经过防火墙或正反向隔离装置；四区下行可由网级四区经跨层防火墙到边缘四区，其他下行先由网级四区进入网级三区，再下行至边缘三区并进入二区或一区；上行先汇入边缘三区，再进入网级三区和网级四区。多单位采用保留完整选择、分批呈现的方式，网级公共对象不重复绘制。

默认仅展示已发布且启用 Path；按范围筛选保留完整跨区 Path；筛选和聚焦不改变聚合范围。Node/Edge 三态、Path 五态遵循基线。停用方向只显示说明及本页只读摘要，不加入实时图层；不创建业务对象整体状态或启停。

只实现 P01。P04/P05 和配置页入口不做假跳转：未交付页面不呈现为可执行业务动作；本页所需对象信息在右侧面板查看。历史页、资源维护、编排、发布、导入和启停操作均不实现。
