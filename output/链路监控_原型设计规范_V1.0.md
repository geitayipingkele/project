## 1. 设计目标与边界

D：原型围绕三类核心任务组织：在统一拓扑中按业务定位状态；以草稿方式编排并确认发布单条 Path；治理可复用 Node/Edge 及其逐条引用。B：界面对象为逻辑 Node、业务 Edge、静态 Path，不展示实例层级，不把静态连线解释为实际执行顺序。

### 1.1 必须守住的业务边界 B

- B：业务对象只用于查询和同时聚焦相关上/下行 Path；没有业务对象整体状态、整体启停或批量动作。
- B：每方向最多一条 Path，允许只有一个方向；上下行不是主备。每条 Path 单独启停、单独显示五态聚合结果。
- B：Node 按稳定资源标识判同；Role 属于 `Path × Node` 且可多选；同一 Path 内同一 Node 只画一次。
- B：Edge 有方向；仅源、目标、方向、业务作用、故障影响范围五项一致时才可建议复用，人工仍可建独立 Edge。
- B：Path 可含串行、分支、汇聚、反向交互；不配置执行步骤。连通性校验忽略方向，孤立 Node（包括单个无边 Node）及断开子图禁止发布、允许保存草稿、没有人工放行入口。
- B：草稿不进入当前监控；校验后由用户查看摘要并确认发布，不新增产品发布审核角色。D：发布失败保持原生效配置与草稿。
- B：停用资源禁止新增引用；若拟发布集合仅保留当前生效集合中的停用引用，可发布其他修改并提示待迁移。首次发布或正式解除后再添加不享受豁免。
- B：引用替换逐条编辑 Path 草稿，不提供批量迁移。共享语义属性不原地改写，应创建替代资源并逐条替换。
- B：Node/Edge 状态为正常、异常、未知；Path 为正常、异常、未知、部分异常、部分未知。业务对象没有聚合状态。
- B：历史按滚动 30×24 小时状态区间展示，时区 Asia/Shanghai；按当前拓扑展示并明确不能恢复当时结构。停用时段不是未知，也不延续停用前状态。
- B：允许外部探针提供 Node/Edge 状态，不要求侵入式埋点；没有真实父子执行信息时不得补造 Span 或播放执行链。
- B：复用既有账户、组织范围和动作权限，不新增产品角色。D：独立交付审核角色只承担产物质量审查。

### 1.2 明确排除及防越界检查 B

B：后续原型不得出现以下入口、状态卡片或暗示：业务对象整体状态/整体启停、批量迁移、主备/双活/替代 Path、Node 实例展开、历史拓扑恢复、自动发现、人工 PathStep/执行顺序/Span DAG、Span 精确回放、强制业务埋点、具体畅通算法、告警联动、新权限系统或独立发布审核队列。D：Path 本体删除没有确认依据，本规范不提供该动作。

## 2. 业务模型与架构约束

### 2.1 界面对象

| 对象 | 原型中的表达 | 不得误表达 |
| --- | --- | --- |
| 业务对象 | 查询项、归组字段、相关方向列表 | 整体状态、整体启停、批量发布 |
| Path | 列表行、画布聚焦集合、详情与草稿 | 线性步骤或主备路径 |
| Node | 唯一逻辑节点卡片，详情按 Path 列 Role | 实例、全局 Role、多次经过产生副本 |
| Edge | 有向连线、作用标签、独立对象详情 | 无向线、执行顺序、仅按端点合并 |
| PathNode/PathEdge | 编排和发布差异中的引用关系 | 把解除引用等同删除资源 |
| Span | 接入说明或最小未匹配提示 | 静态编排对象、由 Edge 推导的真实执行链 |
| 状态区间 | 时间轴和区间列表 | 历史结构版本、查询失败伪装成异常 |

### 2.2 数据和视图分层

D：原型标注三层状态：发布配置层、运行状态层、视图交互层。B：保存草稿只改变配置草稿，发布才替换当前配置；筛选、折叠、聚焦、缩放、隐藏标签只改变视图，绝不改变 Path 聚合组成或状态。

B：统一总览按稳定对象标识融合。D：P03 的单 Path 草稿布局可独立保存，不能反向覆盖统一总览或其他 Path 的视图；区域分组仅作视觉容器，不参与对象判同。

## 4. 页面与字段/控件标准

本章逐项使用 B/D/P：业务含义和禁止项为 B；布局、控件角色、文案和反馈为 D；枚举、映射、时效、规模及保留值引用 P1–P5。控件设计不得提升 D 为业务政策。

### 4.1 P01 链路监控总览

- B：P01查询增加“单位”省—地市二级级联复选，父省只代表省级边缘节点，不联动子地市；删除“业务范围”查询。D：其他查询为业务对象、Path名称/标识、链路类型、查询、重置；样例取值沿用13.1约定。
- D：左侧 Path 列表显示名称、方向、范围、启停可见性、Path 状态、最后更新时间。B：业务对象查询按方向列相关启用 Path，停用方向只给文字和详情入口。
- D：画布包含 Node、Edge、区域容器、状态标识、方向箭头、Edge 作用标签；工具为刷新、适应画布、缩放、清除聚焦。
- D：右侧详情中，Node 显示稳定身份摘要、类型、范围、基础状态、原因/来源、最后更新时间、按 Path 分组 Role；Edge 显示源/目标、方向、作用、影响范围、状态与引用 Path；Path 显示五态和异常/未知组成。
- B：选择业务对象可同时聚焦其相关 Path；选择单 Path 只突出其完整组成；聚焦不改变聚合范围。D：选择对象只更新右栏，聚焦不重排整图并保留视口，清除聚焦恢复查询结果及原视口。
- D：空态文案为“暂无已启用的业务链路”；筛选空态为“没有符合条件的业务链路”；无权限、加载、读取失败、暂无状态分别表达。

### 4.2 P02 业务链路管理

- D：查询字段为业务对象、Path 名称/标识、链路类型、方向、范围、配置状态、启停状态、运行状态；列表列为名称、业务对象、类型、方向、范围、发布状态、有无草稿、启停状态、运行/最后状态、更新时间、操作。
- B：未发布没有运行状态；停用显示停用前最后状态/时间且不能伪装为当前实时结果。D：对应文案为“— 未发布”“已停用；最后状态…，时间…”。
- D：顶部动作采用新建、导入；行内动作采用详情、编辑/继续编辑、启用或停用。B：不得有业务对象整体动作、批量迁移或 Path 删除。
- B：停用停止此 Path 新状态聚合但保留配置和历史；启用需要有效发布配置。D：请求超时进入“结果待确认”，先查询真实状态再允许重试。

### 4.3 P03 业务链路编排

- D：顶栏显示 Path 名称、草稿标识、草稿修订号、关联生效配置/发布时间、最近保存时间；动作按“返回、保存草稿、校验、发布”排列。
- D：左栏提供 Node 搜索（名称、类型、范围）、已有/停用标识、加入按钮、新建 Node。B：停用资源不可新增选择。
- B：画布 Node/Edge 按对象标识去重且 Edge 保持方向。D：画布支持拖动、选择、有向连线、适应画布；重复加入定位已有 Node 并允许维护 Role。
- D：右栏在画布空白时提供 Path 名称、目标、类型、方向、范围、说明、业务对象编码/名称/目标/范围及候选；选择 Node 时提供只读身份摘要、Role 多选、查看资源、从本 Path 移除；选择 Edge 时提供只读语义、查看/替换、解除引用；新建 Edge 时提供源/目标、方向预览、作用/范围字典、说明、复用候选。P：字典、标识与范围来源分别受 P1/P2 及待确认来源约束。
- B：复用候选逐项显示五项匹配证据；人工显式选择“复用已有”或“新建独立关系”；独立 Edge 保留独立标识。D：使用居中候选弹窗，画布不再次合并。
- B：替换 Node 后必须逐条处理相邻 Edge，不能自动篡改共享 Edge；解除引用不删除全局对象。D：移除 Node 确认列出本 Path 内将同步解除的 Edge 引用。
- D：底部校验区固定分“阻止发布”和“提醒”，点击项目定位字段/对象/断开分组。B：V01–V13 中的确认业务边界必须执行，见第 8 章。

### 4.4 P04 业务链路详情

- D：顶栏显示名称、业务对象、方向、范围、发布/启停/运行状态、发布时间；动作仅为有权限的编辑和单条启停。
- B：“当前拓扑”只显示当前生效配置，草稿不参与监控。D：存在草稿时显示“存在未发布修改，监控仍使用已发布配置”；异常和未知清单可定位画布。
- D：“历史状态”提供时间范围、Path 时间轴、当前拓扑、对象区间列表；历史状态默认近 24 小时，可选近 1 小时、7 天、30 天及合法自定义范围。“指标趋势”按第18章独立采用默认近1小时。B：两类查询均不能超出滚动 30×24 小时窗口。
- B：历史按当前拓扑展示且不能恢复当时结构。D：固定提示“按当前拓扑展示；当前图可能与当时组成不同，不能据此完整还原当时的异常原因”，点选时刻只给当前拓扑且有对应历史的对象着色。
- B：停用空档、查询无记录、已存未知三者不可合并。D：分别显示“未生成状态”“无历史记录”“未知”及原因。

### 4.5 P05 拓扑资源

- D：采用 Node/Edge 双页签。Node 列显示名称、类型、稳定标识、范围、资源启停状态、运行状态、发布/草稿引用数；Edge 列显示名称、源→目标、作用、影响范围、资源启停状态、运行状态、引用数。
- D：动作采用查询、查看、新建、修改展示属性、创建替代资源、停用、满足条件时删除。B：已发布资源语义字段只读。
- D：详情展示基础信息、状态与历史入口、已发布引用、草稿引用、操作记录，引用可跳转指定 Path 编辑。B：不得从资产侧直接解除引用或批量迁移。
- B：修改名称/说明/标签前提示影响范围；停用保留已有引用并要求后续逐条调整；不满足条件时禁止删除。D：确认/禁用态列出受影响引用或被引用、曾发布、历史关联等原因。P：P5 未补前不假定具体保留策略。

### 4.6 P06 导入配置

- D：步骤呈现为上传模板、校验与人工确认、创建草稿结果。B：导入需人工核对且只创建草稿。P：模板具体格式和上限为 P4；建议表结构不构成已确认接口。
- D：错误表展示表名、行号、业务编码、字段、原因、修正提示；候选表逐项展示稳定标识和 Edge 五项依据。B：禁止仅按名称自动关联。
- B：预校验失败不写入发布配置；导入只创建草稿并需人工核对，没有“全部发布”“全部迁移”。D：采用全批一次创建草稿/新资源，结果列每条草稿和进入 P03 入口。
- D：重复导入按稳定编码/同一操作标识返回可辨认结果，不静默重复创建；失败后显示本批未落盘及重试方式。P：该原子/幂等方案若受实际规模影响，须在 P4 关闭后再定稿。

### 4.7 共享 Node/Edge 新建与替代资源表单

P03 与 P05 引用同一套资源表单，避免两个入口产生不同业务语义。以下控件类型及“新建必填”来自 PRD 逻辑字段设计，均为 D；共享资源语义不可原地修改、稳定标识判同等边界为 B；枚举/映射来源按 P 标记。

| 对象/字段 | 控件角色 D | 必填与编辑边界（逐项标级） | 数据来源与待补输入 | 校验与反馈 D |
| --- | --- | --- | --- | --- |
| Node 名称 | 单行文本 | D：新建必填；B：展示属性可受控修改 | D：用户输入 | 就近提示；保存失败保留输入 |
| Node 类型 | 选择控件角色 | D：新建必填；B：涉及业务身份时不可原地修改 | P：类型取值来源尚未确认，不并入 P1 | 缺值阻止资源保存/发布引用 |
| 稳定资源标识 | 搜索/输入并触发候选 | B：优先判同；涉及业务身份时不可原地修改 | P2：字段映射与唯一范围 | 显示匹配依据；无标识需人工确认，不自动合并 |
| 所属范围 | 选择/搜索控件角色 | D：新建必填；B：身份变化时建替代资源 | P：业务范围取值来源尚未确认 | 同名跨范围显示差异，不自动合并 |
| Node 说明/标签 | 多行文本/标签输入 | D：可选；B：属于展示属性 | D：用户输入或现有约定 | 修改前显示引用影响范围 |
| Edge 名称/说明/标签 | 文本/标签输入 | D：可选；B：属于展示属性 | D：用户输入或现有约定 | 修改前显示引用影响范围 |
| Edge 源 Node/目标 Node | Node 选择器 | D：新建必填；B：方向由源→目标确定，已发布后不可原地修改 | P2：标识映射 | 缺端点阻止；反转作为语义变化 |
| Edge 业务作用 | 受控字典选择 | D：必填；B：已发布后不可原地修改 | P1：字典 | 候选对比显示差异 |
| Edge 故障影响范围 | 受控字典选择+补充说明 | D：必填；B：已发布后不可原地修改 | P1：字典 | 候选对比显示差异 |

D：表单动作按“取消、保存资源”组织；只有既有权限允许资源维护时可见/可用，服务端仍复验。P03 保存成功后返回当前草稿并选中新资源；P05 新建成功后进入资源详情。创建替代资源预填可复用的展示字段，但不预填为已确认的新语义、不继承状态、不自动替换引用；成功后进入新资源详情，并提供“前往指定 Path 逐条替换”入口。

D：提交中禁用重复操作；稳定标识/Edge 五项出现候选时先人工确认复用或继续独立创建。失败保留输入；权限变化、唯一性冲突或结果不明时展示持久错误并查询真实保存结果。具体接口字段名、唯一范围和字典值仍由 P1/P2 关闭。

## 5. 拓扑视觉语义、聚焦与选择

### 5.1 节点和边

D：Node 使用统一卡片骨架，名称为主标识，类型/范围为辅助信息，状态使用图标+文本/色标；多 Role 只在单 Path 语境下展示。Edge 必须显示箭头；同一对 Node 的多 Edge 使用分离曲线、作用短标签和可选序号，反向 Edge 箭头相反。低缩放可隐藏文字但悬停/选择必须恢复完整语义。

B：实线/虚线不得表示执行顺序，静态拓扑不展示伪造的运行时执行。D：若线型用于选择、候选或停用等视觉状态，图例必须说明且不能与运行状态混淆。

### 5.2 优先级

D：同一对象同时具有运行状态、聚焦、选择、待迁移、停用等信息时，运行状态标记持续可见；选择用蓝色外描边/光晕；聚焦对象保持正常饱和度、非聚焦对象降弱；待迁移用独立警示徽标；停用用文字/徽标而不是伪造灰色未知；颜色不得是唯一信息载体。

### 5.3 选择规则

- D：单击 Node/Edge/Path 更新详情并保持当前聚焦；再次点击或 Escape 清除选择。
- B：业务对象选择产生多 Path 聚焦但不产生业务对象状态；Path 列表仍逐条显示状态。
- D：筛选导致对象离开结果时清除其选择并提示；刷新时对象仍存在则保留视口和选择。
- B：聚焦、筛选、隐藏标签不会改变聚合对象集合；界面不得把“当前可见对象状态汇总”当作 Path 状态。

## 18. P01/P04 指标原型设计输入（当前优先）

### 18.1 P01 当前指标

- Path 摘要在状态之外显示“整链时延 + 指标状态”，未知时显示“— 未知”，不得继续显示旧值。单 Path 聚焦后，画布标题区显示同一值；多 Path 不提供平均或合计。
- Node 卡片保持名称、稳定标识和主状态，只在指标状态异常时增加“指标异常”角标。Node 主状态颜色不随指标角标改变。
- 普通服务详情显示主IP，多IP显示“主IP + N”、完整IP列表、逻辑节点最差时延/丢包率及对应IP。隔离装置详情同时显示正向、反向吞吐量与丢包率并突出当前 Path 方向。防火墙详情显示入向、出向吞吐量和当前总连接数并突出当前流向。
- Edge 详情显示当前 Path 方向、分段时延、丢包率和指标状态。分段时延不放入常驻 Edge 标签。
- Path、Node、Edge 详情均提供“指标趋势”入口；Node/Edge 入口带入当前 Path 和对象。指标块不显示数据来源和采集时间，也不展示或暗示正式阈值。

### 18.2 P04 指标趋势页签

- 页面头部保留返回总览及 Path 名称、单位、方向、状态；页签为“链路总览”“指标趋势”。返回不得重建总览，须保留筛选、聚焦和画布滚动位置。
- 指标趋势顶部为固定整链时延卡片和独立图。下方左侧使用单对象选择器列出当前 Path 的 Node 与 Edge；右侧只渲染当前对象适用指标，禁止铺开全部对象或任意多对象对比。
- 时间工具栏默认近1小时，提供6小时、24小时、7天、30天和自定义。自定义起止不得超过30×24小时；全部图同步范围并展示实际聚合粒度。
- 同量纲序列可同图切换/对比；不同量纲拆成上下对齐的独立图，共用时间轴与联动游标，不使用双轴。
- 时延图默认平均值、P95，提供最大值切换；吞吐量默认平均值，提供最大值切换；丢包率默认平均值、最大值；连接数默认平均值，提供最大值切换。图例按钮可显隐序列。
- 鼠标在任一图移动时，同组图显示相同时间点游标和数值浮层。异常/未知时间桶用背景区间或数据点颜色区分，严重度为异常优先、未知次之。
- 缺失区间必须断线并标“无数据”。三类空态文案固定为：“该对象不适用此指标”“采集失败，当前区间无可用数据”“所选时间超出30天保留期”。
